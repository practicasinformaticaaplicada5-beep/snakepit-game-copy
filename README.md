\# Juego de la Serpiente (Snake Game) en Python 🐍



Este es el clásico juego de la serpiente desarrollado en Python utilizando la librería `pygame`. El proyecto está estructurado de forma modular utilizando Programación Orientada a Objetos (POO).



\## 📂 Estructura del Proyecto



\* `main.py`: Archivo principal que contiene el bucle del juego.

\* `settings.py`: Configuraciones generales (colores, dimensiones, FPS).

\* `snake.py`: Clase que define el comportamiento y dibujo de la serpiente.

\* `food.py`: Clase que define la aparición aleatoria de la comida.



\## 🚀 Requisitos Previos



Asegúrate de tener instalado Python 3.x en tu sistema.
